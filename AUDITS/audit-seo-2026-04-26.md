## 2. Canonicals

| URL | Canonical déclaré | Statut |
|---|---|---|
| `https://beabot.fr/` | `https://beabot.fr` ← **sans trailing slash** | 🔴 |
| Toutes les autres | URL correcte avec trailing slash | ✅ |

**Problème :** La homepage déclare `<link rel="canonical" href="https://beabot.fr">` (sans `/` final) alors que l'URL réelle est `https://beabot.fr/`. Risque de duplicate content signal.

**Fix :** Dans `pages/index.vue`, corriger `siteUrl` → `siteUrl + '/'` ou utiliser `pageUrl` qui inclut le slash.

**Problèmes identifiés :**

1. **Entités HTML non décodées dans les titles** (`&#x27;` = apostrophe, `&amp;` = &) — les moteurs voient le texte brut, certains afficheront l'entité littéralement dans les SERPs. Concerne : `/apps/`, `/comment-reduire…/`, `/images-eco-conception/`, `/l-eco-conception-web/`, `/theme-wordpress-eco-conception/`.

2. **Préfixe `BeAbot -` incohérent** — les pages apps et greenlight utilisent le pattern `Nom — Description | BeAbot` (meilleur), les articles utilisent `BeAbot - Titre` (moins efficace, le mot-clé principal est repoussé). Uniformiser sur `Titre — Mot-clé | BeAbot`.

3. **Title trop long** — `/images-eco-conception/` : 78 caractères, sera tronqué en SERP (~70 max).

4. **Titles trop courts** — `/typographie-ecoconception/` (38), `/wordpress-eco-conception/` (40), `/mentions-legales/` (25).

**Bugs critiques :**

### `[object Object]` sur `/comment-reduire-le-poids-d-un-site-web/`
La meta description affiche littéralement `[object Object]` — un objet JavaScript a été sérialisé sans `.toString()` ou interpolation correcte dans le frontmatter ou le composable `useSeoMeta`. À corriger en urgence : Google verra cette chaîne dans les SERPs.

### Description à 1 caractère sur `/mentions-legales/`
Le champ `description` dans le frontmatter ou le composable est vide ou mal initialisé — seul `L` est récupéré (probablement une apostrophe qui casse le parsing YAML : `L'éco...` sans guillemets).

### Descriptions tronquées
Plusieurs pages ont leur description coupée en pleine phrase, signe que la valeur est coupée côté source (apostrophe non échappée dans le YAML frontmatter cassant le champ).
